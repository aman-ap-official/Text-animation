## ✨ Project Overview

This project demonstrates various **text animation effects** using **pure HTML** and **CSS**. No JavaScript is involved! From fading to zooming, bouncing, and more, these effects can be easily integrated into any webpage to enhance the user experience.

### Featured Text Animations:
- **Fading Text Animation**
- **Zooming Text Animation**
- **Bouncing Text**
- **Smooth Text Animation**
- **Rotating Text**
- **Typing Animation**
- **Waving Text**

---

## 🔧 How It Works

Each animation type uses **pure CSS** to create the effects:

1. **Fading Text Animation**: The text fades in and out continuously using `opacity` and `@keyframes`.
2. **Zooming Text Animation**: The text zooms in and out with scale transformations using `@keyframes`.
3. **Bouncing Text**: The text moves up and down in a bouncing motion using `@keyframes`.
4. **Smooth Text Animation**: The text smoothly transitions between different states using `@keyframes`.
5. **Rotating Text**: The text rotates in a continuous loop using `@keyframes` for smooth rotation.
6. **Typing Animation**: The text appears as if typed by a user with a typing effect using `@keyframes`.
7. **Waving Text**: The text moves in a wave-like motion to create a dynamic visual effect using `@keyframes`.

You can view the demo links above to see each animation in action.
